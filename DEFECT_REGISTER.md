# Defect register — James signals pipeline

Every defect found in the SPX audit (2026-11-09 → 11-11), the message that exposed it,
the fix that closed it, and the test that fails if it returns.

**How to use it.** When a symptom reappears, grep this file for the message id or the
symptom, read that row and run its test:
- test FAILS → the fix regressed; restore it.
- test PASSES but the symptom is live → a *different path* bypasses the fix.
  Fix the path, extend the test. Never weaken the test.

**A row is only closed when the test passes AND the fix sits on the path that failed.**
"Fixed elsewhere" is not closed.

**Automatic lookup.** Every live alert is matched against this register at push time
(`register_hit` in `james_pipe.py`) and the row id is appended, so a resurfaced defect
names itself instead of being re-derived. `python defect_lookup.py --msg <id>` prints
the message text too (it resolves ids the ledger dropped, from `spx_window_raw.txt`).

**Resurfacing post-mortem.** `python defect_lookup.py --postmortem D##` writes a record
to `postmortems/` and, crucially, runs the guard test to decide the diagnosis:
test **FAILS** = the fix regressed, restore it; test **PASSES** = a different path
bypasses it, fix that path and extend the test. Never weaken the test.

`trigger` is the message id that first exposed the defect (or `ops` where it came from
an incident rather than a signal). **Some trigger ids are absent from `signals.csv`** —
3734/3735, 3854-3857 and 3910 are the messages the listener dropped before ingestion
(D21/D22), so they exist in the channel but never reached the ledger. The lookup resolves
them from `spx_window_raw.txt` and marks the source. The ledger is NOT backfilled: it is
the record of what the pipeline actually did, and inserting rows it never processed would
falsify it. The absence IS the evidence.

## Rules the data taught (do not re-litigate)

- The guard is right to refuse a break-even behind spot, but never so strict it parks a
  winner. Over 20 SPX entries: guard-saved −$2,567 vs +$601 missed. Conservative wins.
- Credit/width ≥0.55 carried every good trade; thin credits below it were churn.
- Entry problems cascade: one blocked entry produces a tail of `NO_POSITION` exits.
- NO expiry-weekday gate (probed live 2026-11-12): a Mon/Wed/Fri-vs-Friday table looked
  right until the chain disagreed — QQQ/IWM list Mon–Fri DAILY expiries, msg 3738's
  Tuesday SPX order filled and booked −525, and past-dated chains return 0 contracts
  whether or not the expiry was listed. Settle a park at the session its message named;
  that close answers the direction question. A weekday gate would have mislabelled 25 of
  the first 78 settled rows "would not have been placed".

## Standing limits (not defects)

- Vision proven on 3 stored images only; a new broker layout is unproven.
- Image-only rows with no text are gradable only by eye.
- `itm_cushion_credits` (0.0) and `max_open_retry_hours` (6) are policy knobs, not bugs.
